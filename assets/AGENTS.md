# AI agent guide (any coding agent)

This repo is a **Wix Studio** site. Before editing Velo (`$w('#id')…`), **read
[`wix-elements.md`](./wix-elements.md)** — it lists every element's ID, `$w` type,
layout, child elements, and how to set it (generated by WiXAnything from the real site).

Rules:
- Pick the property by the element's **Type** (see the legend in `wix-elements.md`).
- A `Box`/`MultiStateBox` has **no `.text`** — set its child Text elements (the row's
  **Content / children** column) or use `.changeState()`.
- `HiddenCollapsedElement` may show a recovered type (`Type→Recovered`); `.show()`/
  `.expand()` it first.
- Refresh after editor changes: `npm run wix:full -- --url "<published page>"`
  (or just `npm run wix:full` once the URL is saved).
